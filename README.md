# Runner releases

Public downloads of [Runner](https://runner-landing-six.vercel.app/), the local-first agent board for Mac. The source is private; this repository holds only release builds.

Download the latest build from [Releases](https://github.com/AlejandroCaimares/runner-releases/releases/latest). Each release lists the SHA-256 of its DMG in `SHA256SUMS.txt`.

These beta builds are not notarized. On first open, right-click Runner and choose **Open**.
